Verify a document

Anyone can check whether a document, record or hash is anchored on the ledger. Nothing is uploaded to the blockchain; the file is hashed here and compared with the on-chain hashes.

Check a record

How verification works

  1. Hash. Your input is hashed with SHA-256, exactly as the application does when a record is created.
  2. Look up. The hash is searched among every on-chain data_hash.
  3. Compare. A match shows which vehicle, event and signer it belongs to. If one character of the document changes, the hash changes and the match disappears.

A match proves the document existed unchanged when it was recorded and who signed it. It does not prove the content was true.
